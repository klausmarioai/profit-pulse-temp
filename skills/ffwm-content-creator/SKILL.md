# FFWM Content Creator

Use this skill to produce high-performing content plans and drafts with consistent voice.

## Workflow
1. Start with title + thumbnail concept and hook.
2. Draft in the selected framework from `references/content_frameworks.md`.
3. Keep voice aligned with `references/brand_guidelines.md`.
4. Optionally run:
   - `python scripts/brand_voice_analyzer.py <file>`
   - `python scripts/seo_optimizer.py <file> "<primary-keyword>"`
5. Finalize with platform-specific adjustments from `references/social_media_optimization.md`.
