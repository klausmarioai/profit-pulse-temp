# App User Test Script — Mobile Quick Version

## DM Invite (copy/paste)
Hey [Name] — quick favor?
I’m testing a tiny finance app idea for business owners.
Can you do a **10-min test** and give blunt feedback?
No pitch — just usability/value feedback.
If yes, I’ll send the link.

---

## 30-Second Session Setup
"Thanks. I’m testing the product, not you. Please think out loud and be direct."

## Task
"Open the link, upload sample data (or use demo), then tell me what you think this app helps you do."

## 5 Questions (quick)
1) What do you think this app does?
2) What confused/annoyed you?
3) Did the result feel useful or generic?
4) Would you use this again? (Y/N + why)
5) Would you pay if this worked well? (Y/N/Maybe + rough price)

## Close
"If you could change one thing, what would it be?"

---

## Micro Scorecard (one-liner)
Name | Completed flow (Y/N) | Time-to-value | Main confusion | Use again? | Pay intent | One change
