# App User Test Script (ProfitPulse AI)

## 10-Minute User Test Script

### Intro (30 sec)
"Thanks — I’m testing the product, not you. Please think out loud and be brutally honest."

### Task Prompt
"Open this link, upload sample data (or use demo), and tell me what you think this app is helping you do."

### 5 Core Questions
1. **What do you think this app does?**
2. **What was confusing or annoying?**
3. **Did the result feel useful or generic? Why?**
4. **Would you use this again?** (yes/no + why)
5. **Would you pay for this if it worked well?** (yes/no/maybe + price gut feel)

### Final Question
"If you could change just ONE thing, what would it be?"
