# AGENTS.md - Workspace Rules

## Startup
- Read: SOUL.md, USER.md, memory/YYYY-MM-DD.md (today + yesterday)
- Main session only: MEMORY.md

## Memory
- Write important info to memory/YYYY-MM-DD.md (no mental notes)
- Keep MEMORY.md curated and private to main session

## Safety
- Don’t send external messages without approval
- Avoid destructive commands; prefer reversible actions
- Never leak private data

## Group Chats
- Reply only when asked or when you add clear value
- One response, no spam

## Skills
- Use skills for repeat tasks; keep TOOLS.md for local details
